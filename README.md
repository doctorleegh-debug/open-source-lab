# Open Source Lab

한국어 오픈소스 큐레이션과 영상별 한시 공개 자료 페이지입니다.

## 공개 원칙
- 공식 GitHub 저장소, 관찰 시점의 스타 수, 라이선스, 사용 조건과 출처를 표시합니다.
- 스타 수는 인기 지표이며 안전성 인증이나 품질 보증이 아닙니다.
- 제3자 소개는 발굴용이며 최종 정보는 공식 문서에서 확인합니다.
- 설치·보안 감사·실사용 검증을 수행하지 않은 경우 이를 수행했다고 표현하지 않습니다.
- DM 이용자 이름, 연락처, 팔로우 상태, 대화, 토큰은 이 공개 저장소에 저장하지 않습니다.

## 운영
`data/episodes.json`이 회차와 공개 종료 시간을 정의합니다.
`node scripts/expire.mjs`가 만료 회차의 공개 페이지와 데이터 파일을 삭제하고 홈을 갱신합니다.
GitHub Actions가 정기 점검하며 실행 지연 또는 실패 가능성이 있습니다. 만료 때 실제 URL을 별도로 검증해야 합니다.
GitHub 저장소 이력, 외부 캐시와 이미 내려받은 사본은 회수되지 않습니다. 원본 오픈소스 프로젝트는 삭제하지 않습니다.

## 접근 제한
GitHub Pages는 공개 정적 사이트입니다. DM 단계에서 팔로우를 확인해 링크를 전달할 수 있지만, 페이지 자체는 Instagram 팔로우를 인증하지 않습니다. 링크 재공유 차단이나 개인정보 DB 용도로 사용하지 않습니다.
